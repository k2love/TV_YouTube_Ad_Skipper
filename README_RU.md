## 🚀 Быстрый старт (3 шага)

1. **Скачать APK**: [Прямая ссылка на TV_YouTube_Ad_Skipper.apk](https://raw.githubusercontent.com/k2love/TV_YouTube_Ad_Skipper/main/TV_YouTube_Ad_Skipper.apk)
2. **Передать на ТВ**: Используйте приложение **'Send Files to TV' (SFTTV)** со смартфона или USB-флешку.
3. **Включить спец. возможности**: ТВ [Настройки] ➔ [Спец. возможности] ➔ Включить **[Служба пропуска рекламы YouTube на TV]**!
   - *(Для Google TV 12+: см. [Инструкцию по снятию ограничений](docs/ru/INSTALLATION.md#%EF%B8%8F-3-обязательно-снятие-ограничений-в-google-tv))*

## 🌟 Основные возможности

1. **Пропуск за 0.001 сек и аппаратное отключение звука**: Моментальный клик при появлении кнопки «Пропустить» и автозаглушение рекламы.
2. **🎯 Официальный протокол Lounge (100% без ошибок)**: Прямое получение сигналов с серверов Google без сканирования экрана.
3. **👁️ Пиксельный датчик цвета (Компьютерное зрение)**: Клик точно по белой кнопке после желтого таймера без ложных срабатываний на субтитры.
4. **🛡️ Автопропуск окон Shorts и QR-рекламы**: Закрытие диалогов отключения и рекламных баннеров за 0.1 сек.
5. **🚀 Беспроводное автообновление (OTA)**: Проверка и установка новых версий прямо с GitHub в 1 клик.
