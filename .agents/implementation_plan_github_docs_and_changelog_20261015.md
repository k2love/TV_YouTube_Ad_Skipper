## 3. 부문별 세부 콘텐츠 설계

### (1) 설치법 (Installation Guide)
1. **사전 준비**: 최신 `TV_YouTube_Ad_Skipper.apk` 다운로드 링크 (GitHub Releases / 루트 직다운로드)
2. **방법 1: 가장 쉬운 방법 (초보자용)**
   - TV의 'Send Files to TV' (SFTTV) 앱 또는 USB 드라이브를 통해 APK 전송 후 파일 관리자로 설치.
3. **방법 2: TV 브라우저 / Downloader 앱 활용**
   - AFTVnews Downloader 앱에서 단축 URL 또는 GitHub 링크로 직접 다운로드.
4. **방법 3: PC 무선 ADB 설치 (전문가용 / 원클릭 권한 부여)**
   - `adb connect <TV_IP>:5555` -> `adb install -r TV_YouTube_Ad_Skipper.apk`
5. **⚠️ 핵심: Google TV 12/13/14+ 권한 잠금 해제 가이드**
   - 사이드로딩 앱의 접근성 활성화 시 발생하는 "제한된 설정입니다(Restricted Setting)" 경고 해결 절차 안내:
     - 기기 [설정] -> [앱] -> [특수 앱 액세스] -> [제한된 설정 허용] 또는
     - PC ADB 명령: `adb shell settings put secure enabled_accessibility_services com.example.tvadskipper/.TvAdSkipService` & `adb shell settings put secure accessibility_enabled 1`

### (2) 사용설명서 (User Manual)
1. **모드 1: 🎯 공식 Lounge 프로토콜 모드 (추천 1순위: 100% 무오류)**
   - YouTube TV 앱의 [설정] -> [TV 코드로 연결]에서 12자리 숫자 확인 후 본 앱에 입력하여 페어링.
   - 구글 서버로부터 광고 완료 신호를 직접 수신하여 화면을 보지 않고 0.001초 만에 스킵하는 원리.
   - 하드웨어 완전 자동 음소거(Auto-Mute) 연동 및 광고 종료 후 볼륨 복원.
2. **모드 2: 👁️ 컴퓨터 비전 픽셀 색상 센서 (쇼츠 방해 없는 시각 감지 모드)**
   - 우하단 노란 원형 카운터 감지 중 음소거 유지 -> 흰색 알약 스킵 버튼 노출 시 핀포인트 1회 클릭.
   - 정상 영상 자막/로고 오탐 방지 알고리즘 안내.
3. **보조 보호 기능**:
   - 쇼츠 연결 해제 팝업 0.1초 자동 통과.
   - 좌측 하단 제휴/QR 쇼핑 광고 0.1초 자동 닫기.
4. **유지보수 기능**:
   - 광고 스킵 카운트 초기화 버튼.
   - 무선 자동 업데이트(OTA) 확인 및 인앱 업데이트.
   - 실시간 런타임 이벤트 및 볼륨/스킵 진단 로그 열람.

### (3) 버전별 업데이트 내용 요약 (CHANGELOG)
- **v0.8.0**: 글로벌 13개 주요 언어팩 지원, 전 세계 유튜브 TV 광고 배지 및 스킵 버튼 다국어 감지 알고리즘, 구글 드라이브 로그 업로드 제거, 레이아웃 리소스화.
- **v0.7.2**: 정상 영상 시청 중 노란 자막/로고/조명으로 인한 오음소거(False Positive) 원천 차단.
- **v0.7.1**: 광고 종료 후 볼륨 복원 신뢰성 강화 (하드웨어 볼륨 복구 및 안전 타이머).
- **v0.7.0**: 0ms 칼음소거 및 단일 패스(Single-pass) 노드 탐색으로 유튜브 UI 버벅임 0% 달성.
- **v0.6.9**: 무음 모드 세분화 및 부팅 후 스킵 카운트 리셋 기능.
- **v0.6.5 ~ v0.6.8**: 좌측 하단 QR 제휴 쇼핑 오버레이 핀포인트 좌표(12.4%, 89.3%) 가상 타격 및 쇼츠 팝업 자동 통과.
- **v0.6.0 ~ v0.6.4**: GitHub 기반 무선 자동 업데이트(OTA) 시스템 구축.
- **v0.5.x**: 공식 Lounge 프로토콜 듀얼 엔진 도입 및 기본 스킵 알고리즘 개발.
