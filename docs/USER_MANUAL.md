# 📖 TV YouTube Ad Skipper 상세 사용설명서

`TV YouTube Ad Skipper`는 안드로이드 TV 환경에서 공식 YouTube 앱의 광고를 가장 빠르고 안정적으로 자동 건너뛰기 및 음소거해 주는 올인원 유틸리티입니다.

---

## 🎯 1. 핵심 듀얼 엔진 동작 모드

본 앱은 상황에 맞추어 **두 가지 강력한 모드**와 **저사양 TV 전용 완전 동면(Deep-Sleep) 아키텍처**가 유기적으로 상호 보완하며 동작합니다.

### 🌟 [모드 1] 공식 Lounge 프로토콜 모드 (추천 1순위: 100% 무오류)
화면을 시각적으로 스캔하지 않고, YouTube의 순정 **'TV 코드로 연결'** 공식 프로토콜 세션을 활용합니다.

- **원리**: 스마트폰 유튜브 앱과 스마트TV가 연동될 때 사용하는 Google Lounge 웹소켓 채널을 열어, 구글 서버가 보내주는 광고 상태 변경 신호(`onAdStateChange`, `isSkipEnabled=true`)를 0.001초 만에 직접 수신하여 스킵합니다.
- **장점**: 화면 자막, 영상 속 화려한 그래픽, UI 변경의 영향을 전혀 받지 않으며 100% 무오류로 동작합니다.
- **연결 방법 (최초 1회만 진행)**:
  1. TV에서 **공식 YouTube 앱**을 실행합니다.
  2. 왼쪽 메뉴 맨 아래 **[설정]** ➔ **[TV 코드로 연결]**로 이동합니다.
  3. 화면에 나타난 **12자리 숫자 코드**(예: `123 456 789 012`)를 확인합니다.
  4. **TV Ad Skipper** 앱을 열고 [Lounge 프로토콜 카드]의 입력창에 12자리 숫자를 입력한 뒤 **[TV 연결하기]** 버튼을 누릅니다.
  5. 상태가 초록색 **`연결됨 (YouTube on TV) - 자동 감시 작동 중`**으로 바뀌면 설정 완료! TV가 재부팅되어도 백그라운드에서 자동으로 재연결을 유지합니다.

---

### 💤 [신규] 저사양 Google TV(TCL·Hisense) 4K 60fps 완전 동면(Deep-Sleep) 아키텍처
보급형 Google TV(TCL, Hisense 등)에서 고화질 4K 60fps HDR 영상 재생 시 화면이 주기적으로 '툭툭 끊기는' 현상을 해결하기 위한 신기술입니다.

- **본 영상 재생 중 100% 동면**: 본 영상 시청 중(`isAdPlaying == false`)에는 백그라운드 센티넬 폴링 루프를 완전히 멈추고(`removeCallbacks`), 런타임에 접근성 이벤트 수신(`eventTypes = 0`)을 비활성화하여 CPU/GPU/IPC 부하를 **0.0%**로 유지합니다.
- **상시 화면 캡처 폐지**: 본 영상 시청 중 주기적으로 화면을 캡처하던 기존 방식을 전면 제거하여 하드웨어 비디오 오버레이(HWC) 플레인이 해제되지 않도록 원천 보호합니다.
- **광고 발생 시에만 즉시 깨우기 (Wake-up)**: `LoungeManager`가 광고 시작 신호를 수신하는 즉시 0.001초 만에 하드웨어 음소거를 걸고 일시적으로 센티넬을 깨워 스킵을 보조한 뒤, 본 영상 시작 즉시 다시 완전 동면으로 복귀합니다.

---

### 🛒 [신규] 비픽셀(Non-Pixel) YouTube Innertube API 기반 QR 쇼핑 광고 감지
- **원리**: 상시 화면 캡처 대신, 본 영상 진입 시 유튜브 내부 API(`https://www.youtube.com/youtubei/v1/next`)로 해당 영상의 쇼핑 메타데이터(`shoppingOverlay`, `merchandiseShelf`, `수수료 지급` 등) 유무를 **단 1회 사전 조회**합니다.
- **무부하 유지**: 쇼핑 태그가 없는 95% 이상의 일반 영상(영화, 음악, 예능 등)에서는 화면 캡처를 **0회** 유지하며, 쇼핑 상품이 등록된 5% 미만의 영상에서만 본 영상 진입 직후(`+4.0초`, `+8.0초`) 핀포인트로 닫기를 수행합니다.

---

### 👁️ [모드 2] 컴퓨터 비전 픽셀 색상 센서 (쇼츠 방해 없는 시각 감지 모드)
Lounge 코드를 입력하지 않더라도 안드로이드 접근성 서비스와 초경량 화면 색상 분석 엔진을 통해 순수 로컬로 동작하는 모드입니다.

- **원리**: 
  1. 광고가 시작되면 화면 우하단의 **노란색 원형 카운트다운 타이머**를 실시간 감지하여 음소거를 칼같이 유지합니다.
  2. 카운트다운이 종료되고 **흰색 알약 바탕의 스킵 버튼(Skip Ad)**이 화면에 나타나는 순간을 픽셀 단위로 정확히 포착하여 정밀 타격(1회 핀포인트 클릭)합니다.
- **영상 오탐 방지 알고리즘**:
  - 일반 영상 시청 중 노란 자막, 황혼/조명, 노란 옷이나 로고 등이 화면에 나타나더라도 절대 스킵 버튼이나 광고로 오판하지 않도록 비광고 재생 중 픽셀 검사를 철저히 격리합니다.

## 📊 3. 모니터링 및 편의 기능

### 광고 스킵 횟수 카운터 및 초기화
- 부팅 후 앱이 자동으로 스킵한 광고 횟수가 누적 표시됩니다.
- 우측의 **[카운트 초기화]** 버튼을 누르면 즉시 0회로 리셋됩니다.

### 🚀 무선 자동 업데이트 (OTA, Over-The-Air)
- 앱이 켜질 때마다 GitHub 공식 저장소에 새 버전 APK가 있는지 자동으로 확인합니다.
- 새 버전이 발견되면 팝업으로 변경 내역을 보여주며, **[지금 업데이트]**를 누르면 앱 내에서 즉시 다운로드하여 원클릭으로 업데이트를 진행합니다.
- 메인 화면의 **[🔄 지금 업데이트 확인]** 버튼으로 언제든 수동 확인이 가능합니다.

### 📋 실시간 런타임 진단 로그 뷰어
- 광고 감지 시간, 볼륨 조절 수치, 픽셀 센서 동작 내역이 TV 내부 파일에 안전하게 기록됩니다.
- **[📄 실시간 로그 보기]**를 누르면 최근 150줄의 로그를 TV 화면에서 직접 확인하고 초기화할 수 있습니다.
- *(v0.8.0부터 개인정보 보호를 위해 외부 구글 드라이브 전송은 완전히 제거되었으며 오직 기기 로컬에서만 안전하게 확인됩니다)*

## ❓ 4. 자주 묻는 질문 (FAQ)

**Q. 광고가 스킵된 후에도 소리가 안 돌아와요.**
> 앱 메인 화면에서 **[스킵 감지 테스트 / 로그 갱신]** 버튼을 누르거나 리모컨 볼륨 키를 한 번 누르면 즉시 복원됩니다. v0.7.1부터는 광고 종료 2초 후 볼륨이 누락되지 않도록 안전 복원 타이머가 작동합니다.

**Q. Lounge 코드가 자꾸 풀려요.**
> YouTube TV 앱의 [TV 코드로 연결] 번호는 구글 정책상 주기적으로 갱신될 수 있습니다. 코드가 만료되어 연결이 해제되면, YouTube 앱에서 새 12자리 숫자를 받아 다시 입력해 주시면 됩니다. 연결이 안 된 상태에서도 [모드 2: 픽셀 센서]가 기본 백업으로 자동 작동합니다.
