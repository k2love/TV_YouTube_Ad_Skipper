# 📖 TV YouTube Ad Skipper - 详细用户手册

`TV YouTube Ad Skipper` 是一款专为 Android TV 打造的一体化后台工具，可自动跳过 YouTube 广告并实现硬件级自动静音。

---

## 🎯 1. 双引擎运行模式

### 🌟 [模式 1] 官方 Lounge 协议模式 (推荐首选: 100% 零误差)
- **原理**: 通过 YouTube 官方「通过电视代码关联」WebSocket 会话直接接收 Google 服务器的广告结束信号，无需屏幕检测，0.001 秒瞬间跳过。
- **关联步骤**:
  1. 打开电视上的 YouTube 应用，进入 [设置] ➔ **[通过电视代码关联]**。
  2. 查看并记录屏幕上显示的 **12 位数字代码**。
  3. 打开 TV Ad Skipper，输入 12 位代码后点击 **[关联电视]**。
  4. 状态变为绿色的「已关联」即设置完成，重启后依然自动重连。

---

### 💤 [新功能] 入门级 Google TV 专用「完全休眠 (Deep-Sleep) 架构」
彻底解决 TCL、海信等入门级电视在播放 4K 60fps HDR 视频时的卡顿与掉帧问题。

- **正片播放期间 100% 休眠**: 正片播放时（`isAdPlaying == false`）彻底停止后台巡视循环，并将无障碍事件设置为 `serviceInfo.eventTypes = 0`，实现 **0.0% CPU/GPU/IPC 占用**。
- **废除周期性截屏**: 彻底取消正片播放期间的屏幕截图，保护硬件视频图层（HWC），杜绝微卡顿。
- **仅在广告期间快速唤醒**: 广告出现时在 0.001 秒内静音并临时唤醒巡视协助跳过，正片开始后立即回归深度休眠。

---

### 🛒 [新功能] 基于 YouTube Innertube API 的无像素 QR 购物广告检测
- **原理**: 不再持续截屏，而在视频开始时调用内部 API（`/youtubei/v1/next`）预先检测 1 次商品元数据。
- **零额外开销**: 在 95% 以上的普通视频中保持 **0 次截屏**并完全休眠；仅在包含商品标签的 <5% 视频中，于 `+4.0秒` 和 `+8.0秒` 时精准关闭二维码卡片。

---

### 👁️ [模式 2] 计算机视觉像素颜色传感器
- **原理**: 广告期间监测右下方黄色圆形倒计时，倒计时结束后对白色跳过按钮进行定点点击。
- **误检防护**: 正片播放时彻底停用传感器，杜绝因黄色字幕或背景光导致的误静音。

---

## 🛡️ 2. 主要设置功能

- **广告自动静音**: 强制广告期间静音，正片开始时精准恢复原音量。
- **Shorts 断开连接弹窗自动跳过**: 0.1 秒自动确认。
- **QR 购物广告自动关闭**: 结合 Innertube 预判，在购物视频中自动关闭左下角推广弹窗。
- **无线自动更新 (OTA)**: 启动时自动检查 GitHub 最新构建并一键更新。
