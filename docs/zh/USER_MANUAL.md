# 📖 TV YouTube Ad Skipper - 详细用户手册

针对 Android TV 环境中 YouTube 官方应用的广告跳过与硬件静音操作手册。

---

## 🎯 1. 双引擎运行模式

### 🌟 [模式 1] 官方 Lounge 协议模式 (首选推荐: 100% 零误差)
- **运行原理**: 利用 YouTube 官方「通过电视代码关联」会话直接从 Google 服务器接收广告结束信号，无需屏幕视觉扫描，0.001秒极速跳过。
- **关联步骤**:
  1. 在电视上打开 YouTube ➔ [设置] ➔ **[通过电视代码关联]**。
  2. 获取屏幕上显示的 **12位数字代码**。
  3. 打开 TV Ad Skipper，输入12位代码并点击 **[关联电视]**。

### 👁️ [模式 2] 计算机视觉像素颜色传感器
- **运行原理**: 广告播放时监测右下角黄色圆环倒计时，结束后对白色跳过按钮进行定点点击。
- **防误判保障**: 在非广告视频播放期间完全关闭传感器检测，避免因视频字幕或黄色背景发生误静音。

---

## 🛡️ 2. 主要功能设置
- **硬件级自动静音**: 广告期间完全静音，正片开始瞬间恢复音量。
- **Shorts 弹窗自动跳过**: 0.1秒极速通过投屏断开确认。
- **二维码推广广告自动关闭**: 0.1秒精确坐标关闭左下角推广弹窗。
- **无线自动更新 (OTA)**: 启动时自动从 GitHub 检查新版本。
