# 📖 TV YouTube Ad Skipper - Panduan Pengguna

Panduan mode operasi dan setelan aplikasi untuk Android TV.

---

## 🎯 1. Mode Operasi

### 🌟 [Mode 1] Protokol Lounge Resmi (100% Bebas Galat)
- **Cara Kerja**: Terhubung via \'Tautkan dengan kode TV\'. Melewati iklan dalam 0,001s langsung dari sinyal Google tanpa memindai layar.
- **Cara Menautkan**: Buka YouTube di TV ➔ [Setelan] ➔ **[Tautkan dengan kode TV]**, masukkan 12 digit ke TV Ad Skipper, dan klik **[Tautkan TV]**.

### 👁️ [Mode 2] Sensor Warna Piksel
- **Cara Kerja**: Memantau timer kuning dan mengklik tombol putih saat muncul. Dinonaktifkan selama video normal.

---

## 🛡️ 2. Fitur Utama
- **Bisukan Otomatis**: Membisukan iklan dan mengembalikan volume saat video dimulai.
- **Lewati Dialog Shorts**: Menutup pop-up pemutusan dalam 0,1s.
- **Tutup Iklan QR**: Menutup banner belanja di kiri bawah dalam 0,1s.
- **Pembaruan OTA**: Memeriksa versi baru di GitHub secara otomatis.
