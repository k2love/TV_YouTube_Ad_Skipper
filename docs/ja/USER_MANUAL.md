# 📖 TV YouTube Ad Skipper - 詳細マニュアル

`TV YouTube Ad Skipper` は、Android TV 向けの公式 YouTube 広告自動スキップ＆ハードウェア自動ミュートユーティリティです。

---

## 🎯 1. デュアル動作モード

### 🌟 [モード 1] 公式 Lounge プロトコルモード (推奨: 100% エラーフリー)
- **仕組み**: YouTube 公式「テレビコードでリンク」セッション経由で Google サーバーから広告完了シグナルを受信し、画面監視なしで 0.001 秒でスキップします。
- **連携方法**:
  1. テレビの YouTube アプリを開き、[設定] ➔ **[テレビコードでリンク]** へ進む。
  2. 表示された **12桁の数字** を確認。
  3. TV Ad Skipper アプリを開き、12桁を入力して **[テレビをリンク]** をクリック。
  4. ステータスが緑色の「リンク完了」になれば設定完了。

---

### 💤 [新機能] 低スペック Google TV 向け「完全休眠 (Deep-Sleep) アーキテクチャ」
TCL や Hisense などの低価格帯 Google TV で 4K 60fps HDR 動画再生時に発生するカクつき（フレーム落ち）を根本的に解消します。

- **本編再生中は 100% 休眠**: 本編再生中（`isAdPlaying == false`）はバックグラウンドの監視ループを完全停止し、`serviceInfo.eventTypes = 0` によりアクセシビリティイベントの生成を遮断（CPU/GPU/IPC 負荷 0.0%）。
- **常時画面キャプチャの完全撤廃**: ハードウェアオーバーレイプレーン（HWC）の解除を防止し、4K 映像の滑らかな再生を保護。
- **広告時のみ即時起動**: 広告開始時に 0.001 秒でミュートし、一時的に監視を再開してスキップしたのち、本編開始時に即座に完全休眠へ復帰。

---

### 🛒 [新機能] 非ピクセル YouTube Innertube API 活用 QR ショッピング広告検知
- **仕組み**: 画面を常時キャプチャする代わりに、動画開始時に YouTube 内部 API（`/youtubei/v1/next`）でショッピングメタデータの有無を 1 回のみ事前照会。
- **ゼロ負荷**: 95% 以上の通常動画ではキャプチャ 0 回で完全休眠を維持し、商品タグ付き動画（5% 未満）でのみ `+4.0秒`・`+8.0秒` にピンポイントで閉じます。

---

### 👁️ [モード 2] コンピュータビジョン ピクセルカラーセンサー
- **仕組み**: 右下の黄色い円形タイマー終了後、白いスキップボタンが表示された時のみ 1 回ピンポイントクリック。
- **誤検知防止**: 通常動画の再生中はピクセルセンサーを完全停止し、字幕やロゴによる誤ミュートを防ぎます。

---

## 🛡️ 2. 主な設定機能

- **広告自動ミュート**: 広告中に音声を自動で消音し、本編開始時に元の音量へ復元。
- **Shorts 切断ポップアップ自動通過**: 0.1秒で自動確認。
- **QR ショッピング広告自動消去**: Innertube 事前照会により、ショッピング動画でのみ左下の提携広告を自動で閉じる。
- **ワイヤレス自動更新 (OTA)**: 起動時に GitHub の新バージョンを自動検知。
