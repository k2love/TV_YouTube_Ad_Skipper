# 📖 TV YouTube Ad Skipper - Manuel d\'utilisation

Modes de fonctionnement et paramètres de l\'application pour Android TV.

---

## 🎯 1. Modes de fonctionnement

### 🌟 [Mode 1] Protocole officiel Lounge (100 % sans erreur)
- **Fonctionnement** : Connexion via « Associer avec un code TV ». Ignore les pubs en 0,001 s directement depuis les signaux Google sans analyser l\'écran.
- **Connexion** : Sur YouTube TV, allez dans [Paramètres] ➔ **[Associer avec un code TV]**, notez le code à 12 chiffres, entrez-le dans TV Ad Skipper et cliquez sur **[Associer le téléviseur]**.

### 👁️ [Mode 2] Capteur de couleur de pixels
- **Fonctionnement** : Surveille le minuteur jaune et clique sur le bouton blanc dès son apparition. Désactivé pendant les vidéos normales pour éviter les faux positifs.

---

## 🛡️ 2. Paramètres principaux
- **Sourdine automatique** : Coupe le son des publicités et le restaure lors de la reprise du contenu.
- **Passage des Shorts** : Ignore l\'invite de déconnexion en 0,1 s.
- **Fermeture des QR codes** : Ferme automatiquement les bannières d\'achat dans le coin inférieur gauche.
- **Mise à jour OTA** : Recherche les nouvelles versions sur GitHub à chaque démarrage.
