# 📖 TV YouTube Ad Skipper - Руководство пользователя

`TV YouTube Ad Skipper` — это универсальная фоновая утилита для Android TV, которая обеспечивает мгновенный пропуск рекламы и аппаратное автоотключение звука в официальном приложении YouTube.

---

## 🎯 1. Режимы работы

### 🌟 [Режим 1] Официальный протокол Lounge (Рекомендуется: 100% без ошибок)
- **Принцип работы**: Подключение через официальную сессию YouTube «Подключение через код на ТВ». Получает сигналы завершения рекламы напрямую с серверов Google и пропускает рекламу за 0.001 секунды без сканирования экрана.
- **Подключение**:
  1. Откройте YouTube на ТВ, перейдите в [Настройки] ➔ **[Подключение через код на ТВ]**.
  2. Запишите **12-значный код**.
  3. Откройте TV Ad Skipper, введите код и нажмите **[Подключить ТВ]**.
  4. Зеленый статус подтвердит успешное подключение с автопереподключением при перезагрузке.

---

### 💤 [Новое] Архитектура глубокого сна (Deep-Sleep) для бюджетных Google TV
Устраняет подергивания и потерю кадров при воспроизведении 4K 60fps HDR на недорогих Smart TV (TCL, Hisense и др.).

- **100% сон во время основного видео**: При воспроизведении контента (`isAdPlaying == false`) фоновый цикл мониторинга полностью останавливается (`serviceInfo.eventTypes = 0`), обеспечивая **0.0% нагрузки на CPU/GPU/IPC**.
- **Отказ от периодических скриншотов**: Предотвращает отключение аппаратного видеооверлея (HWC), сохраняя плавность 4K.
- **Мгновенное пробуждение только при рекламе**: Мгновенный звук 0.001с, пропуск и моментальный возврат в глубокий сон.

---

### 🛒 [Новое] Беспиксельное обнаружение QR-рекламы через YouTube Innertube API
- **Принцип работы**: Вместо постоянных снимков экрана выполняется единичный запрос к `/youtubei/v1/next` в начале видео для проверки товарных метаданных.
- **Нулевая нагрузка**: 0 скриншотов на 95%+ обычных видео и точечное закрытие на 4-й и 8-й секундах только на видео с товарами.

---

### 👁️ [Режим 2] Пиксельный датчик цвета (Компьютерное зрение)
- **Принцип работы**: Отслеживает желтый круглый таймер и точно кликает по белой кнопке пропуска при его завершении.
- **Защита от ложных срабатываний**: Полностью отключается во время обычного видео, предотвращая реакцию на желтые субтитры.

---

## 🛡️ 2. Основные настройки

- **Автоотключение звука рекламы**: Заглушает рекламу и точно восстанавливает прежнюю громкость.
- **Автопропуск диалогов Shorts**: Закрывает окна подтверждения за 0.1с.
- **Автозакрытие QR-рекламы товаров**: Закрывает баннеры только на видео с подтвержденными товарами.
- **Беспроводное автообновление (OTA)**: Проверка и установка новых версий прямо с GitHub в 1 клик.
