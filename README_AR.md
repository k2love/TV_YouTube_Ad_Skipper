## 🚀 البداية السريعة (3 خطوات سهلة)

1. **تحميل ملف APK**: [تحميل مباشر TV_YouTube_Ad_Skipper.apk](https://raw.githubusercontent.com/k2love/TV_YouTube_Ad_Skipper/main/TV_YouTube_Ad_Skipper.apk)
2. **إرسال إلى التلفزيون**: أرسل من الهاتف عبر تطبيق **'Send Files to TV' (SFTTV)** أو فلاشة USB.
3. **تفعيل إمكانية الوصول**: على التلفزيون: [الإعدادات] ➔ [إمكانية الوصول] ➔ تفعيل **[خدمة تخطي إعلانات يوتيوب على التلفزيون]**!
   - *(في Google TV 12+: راجع [دليل فك الإعدادات المقيدة](docs/ar/INSTALLATION.md#%EF%B8%8F-3-إعداد-هام-فك-الإعدادات-المقيدة-في-google-tv))*.

👉 **[دليل التثبيت المفصل (docs/ar/INSTALLATION.md)](docs/ar/INSTALLATION.md)**

## 🌟 الميزات الرئيسية

1. **تخطي فوري خلال 0.001 ثانية وكتم تلقائي**: نقر فوري وكتم الصوت أثناء الإعلانات.
2. **🎯 بروتوكول Lounge الرسمي (بدون أخطاء 100%)**: ربط مباشر عبر رمز التلفزيون لتلقي الإشارات من خوادم Google.
3. **👁️ مستشعر ألوان البكسل**: نقر دقيق على زر التخطي دون التأثر بترجمة الفيديو.
4. **🛡️ إغلاق إشعارات Shorts وإعلانات QR**: تخطي في 0.1 ثانية.
5. **🚀 تحديث هوائي لاسلكي (OTA)**: فحص تلقائي وتحديث من GitHub عند التشغيل.
